# Sample conversations

01-04 are generated by `python eval/run_transcripts.py` with the default offline backend, so they are reproducible verbatim.

- [`01_user1_action_comedy_fan.md`](01_user1_action_comedy_fan.md) - User 1 - 190 ratings, average 4.33, action/comedy fan. The dense-history case.
- [`02_user15_scifi.md`](02_user15_scifi.md) - User 15 - 85 ratings, average 3.55, sci-fi leaning. Tests content search and multi-hop.
- [`03_user30_cold_start.md`](03_user30_cold_start.md) - User 30 - only 18 ratings, average 4.61. The cold-start case, plus a hard constraint.
- [`04_edge_cases.md`](04_edge_cases.md) - Deliberate edge cases: no user id, a film that is not in this filtered catalogue, a nonexistent user, and an unparseable request.
- [`05_llm_backend.md`](05_llm_backend.md) - the optional LLM backend (gpt-4o-mini) on four turns, two of them baited to test grounding. Generated by `eval/run_llm_transcript.py`; needs an API key and is not reproducible verbatim.
